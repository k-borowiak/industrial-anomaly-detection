# Industrial Anomaly Detection – Motor & Compressor Monitoring

This project aims to build an unsupervised anomaly detection pipeline for industrial equipment based on temperature and electrical load signals. The objective is to learn normal operating behavior of machinery and detect deviations early, without relying on labeled fault data, following principles commonly used in industrial predictive maintenance.

The project uses the MetroPT‑3 dataset (UCI Machine Learning Repository), which contains real-world, multivariate time-series data collected from a metro train air compressor system, including motor current, temperature, and pressure signals sampled at 1 Hz over several months of operation.
